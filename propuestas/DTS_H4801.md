# #DTS #H4801 Anexo a informe de albarán con datos de envases

Los objetivos de este proyecto son:

+ Cumplir las novedades de la ley de envases añadiendo un anexo a los albaranes de venta en el que se desglosan los envases por línea de albarán.

## Propuesta realizada a petición de:
Eugenia

## Estructura

### Facturación / Albarán / Imprimir
Añadiremos al informe de albarán una última página que incluirá el desglose de envases similar al informe que puede sacarse a partir de las facturas de venta con las siguientes diferencias:

+ Incluiremos el dato de referencia para cada envase, además de su descripción
+ No incluiremos datos económicos (informe no valorado)

El anexo aparecerá siempre de forma automática (no será opcional) al imprimir o enviar por email un albarán de venta
