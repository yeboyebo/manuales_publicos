# #DTS #H4804 Actualización automática (periódica) de estado de envío a Dachser de albaranes

Los objetivos de este proyecto son:

+ Tener actualizado el estado de envío en los albaranes de forma que no haya que hacerlo de manualmente

## Propuesta realizada a petición de:
Roberto

## Estructura

### Olula / Almacen / albaran_venta / revisa_estado_dachser
Crearemos un caso de uso *almacen.albaran_venta.revisa_estado_dachser*
+ Entrada (no es necesaria)

+ Condiciones (no hay)

+ Acción:
    + Para cada los albarán que esté enviado a Dachser y no haya pasado todavía a estado Enviado:
        + Llamada al webservice de consulta de estado de envío de Dachser
        + Actualización, si procede, del estado del albarán

+ Eventos:
    + Se genera un evento *almacen.albaran_venta.envio_dachser_triggered* que no necesita parámetros.
    
+ Suscripciones:
    + *almacen.albaran_venta.envio_dachser_triggered* > *almacen.albaran_venta.revisa_estado_dachser*

Programaremos una tarea horaria para publicar un evento *almacen.albaran_venta.envio_dachser_triggered* cada hora.
