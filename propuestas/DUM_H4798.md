# #DUM #H4798 Modificación de informe de presupuesto y factor de beneficios en ventas

Los objetivos de este proyecto son:

+ Modificar el informe de presupuesto con detalle de líneas según especificaciones de PDF aportado
+ Usar un factor de beneficio para calcular los precios de venta en función del precio de coste y de dicho factor.

## Propuesta realizada a petición de:
Cristina

## Estructura

### Almacén / Artículos. Precio base y factor
Añadiremos a la tabla de artículos los siguientes campos:

+ Factor. Decimal (4,4). Valor por defecto 0.

Añadiremos a la pantalla de artículos (pestaña venta) los siguientes campos:
    + Precio base, mapeado al precio de coste que se ve en la pestaña de Compras.
    + Factor

Modificaremos los cálculos de campos de la ventana de artículos de la siguiente forma:

+ Si cambia el precio base o el factor y el factor no es cero:
    + Precio venta = Precio base x Factor

+ Si cambia el precio venta y el precio base no es cero:
    + Factor = Precio venta / Precio base

### Facturación / Presupuestos. Precio base y factor
Modificaremos la tabla de líneas de presupuestos de venta para contener dos nuevos campos:
+ Precio base
+ Factor

Comportamiento:
+ Al cargar una nueva referencia, se cargarán automáticamente los valores de Precio base, Factor y PVP Unitario de la ficha de artículo.
+ La modificación de estos campos lanzará los mismos cálculos que se describen en el punto de _Almacén / Artículos. Precio base y factor_.

### Facturación / Informe de presupuesto (detalle con líneas)
Haremos las siguientes modificaciones:

+ En el menú de tipos de documento a imprimir, cambiaremos la opción de _Informe presupuestos venta con detalle líneas_ a _Escandallo_.

+ En el informe de detalle de líneas:

    + Modificaremos la etiqueta _Presupuesto_ por _Escandallo_.
    + Eliminaremos todos los datos de contacto de Duma, excepto el nombre de la empresa
    + Compactaremos el resto de datos para que la cabecera sea menos alta
    + En la tabla de productos:

        +  Quitaremos la columna de referencia.
        + Modificaremos las columnas a la derecha de descripción para mostrar Cantidad, Factor, Precio Base, Total.

    + Mostraremos en el pie de cada partida el total de todas sus líneas.
