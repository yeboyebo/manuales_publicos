# #MON #H4802 Generar albaranes diarios en recepción de cosido

Los objetivos de este proyecto son:

+ Agilizar la generación de albaranes generándolos automáticamente a partir de los datos de unidades cosidas

## Propuesta realizada a petición de:
Juan Antonio

## Estructura

### Almacén / Módulos
Añadiremos a la pantalla el siguiente campo:

+ Coste cosido. 

### Producción / UPs
Añadiremos a la tabla de unidades de producto un nuevo campo

+ Id Línea Albarán cosido.

### App / Recepción de cosido
Migraremos a Olula la pantalla de recepción de cosido

Incluiremos un filtro que permitirá filtrar, al menos:
    + Cosedor
    + Fechas de cosido
    + Albaranado (sí / no / todos) > hay una línea de albarán asociada a la UP

Incluiremos un botón Albaranar que se habilite cuando haya uno o más unidades seleccionadas en la multiselección.

Crearemos un caso de uso *albaranar_cosido*
+ Entrada:
    + Lista de UPs a incluir
    + Id del cosedor

+ Condiciones
    + Todas las UPs deben ser del mismo cosedor
    + No puede haber ninguna UP asociada ya a una línea de albarán

+ Acción:
    + Para el cosedor, buscamos su proveedor asociado
    + Para cada UP, buscamos la UP o una proyección que incluya su coste
    + Se genera un albarán de compra para el proveedor del cosedor con una línea por cada UP. La descripción de la línea es:
        + Fecha - Id. UP - Descripción UP
    + Se actualizan las líneas de UP con los id de las correspondientes líneas del albarán

+ Eventos:
    + Para cada línea creada se genera un evento compras.albaran.linea_cosido_creada que incluye:
        + Id Linea
        + Id UP
    
+ Suscripciones:
    + compras.albaran.linea_cosido_creada > Nuevo caso de uso en produccion/lote/asociar_albaran_cosido que asocia la línea a la UP
    + compras.albaran.linea.borrada (ya existe) > Nuevo caso de uso en produccion/lote/desasociar_albaran_cosido que desasocia la línea a la UP (si se encuentra UP asociada)
