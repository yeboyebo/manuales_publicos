# #MON #H4806 Grupos de devoluciones en webapp para agentes y webapp de clientes

Los objetivos de este proyecto son:
+ Exponer las unidades de producto devueltas en cada pedido de forma agrupada, con una foto adjunta para que los comerciales puedan consultarlos y convertirlos en pedidos.

## Estructura

### Agrupación de UPs devueltas
Crearemos una nueva tabla de Grupos de devoluciones. Sus campos son:

+ Id. 
+ Pedido. Código del pedido del que proviene el grupo.
+ Foto: Foto de la devolución.
+ Pedido venta: Pedido en el que se vende la devolución.

Modificaremos la tabla de devoluciones de UP para crear un nuevo campo asociado con el grupo
+ idGrupo

### Crear devolución
Crearemos un caso de uso *crear_devolución*
+ Entrada:
    + Id Pedido
    + Lista de UPs devueltas

+ Condiciones
    + El pedido y las UPs existen
    + Ninguna de las UPs están ya devueltas
    + Las UPs están en estado 'CARGADO', 'EN CARGA', 'TERMINADO'

+ Acción:
    + Se crea un grupo de devolución asociado al pedido y a las UPs
    + Se guarda el grupo

+ Eventos:
    + No hay
    
+ Suscripciones:
    + No hay

### Eneboo / Crear devolución
Usaremos el nuevo caso de uso de Olula en lugar de la actual funcionalidad nativa para crear las devoluciones en grupos

### Webapp / Crear pedido desde grupos de devoluciones
Crearemos una nueva opción en ventas/devoluciones_disponibles que mostrará un listado de los grupos de devolución disponibles

La vista de Devoluciones disponibles permitirá:
    + Asignar una foto a la devolución (solo en app agentes)
    + Ver la foto
    + Multiselección de grupos de devolución y creación de pedidos

Generación de pedido:
+ Webapp de agentes: Vista de selección de cliente / dirección + botón Crear pedido
+ Webapp de clientes: Vista de selección de dirección + botón Crear pedido

Estados:
+ Consulta:
    + Descripción: El usuario filtra y consulta devoluciones
    + Eventos:
        + El usuario selecciona uno o más grupos y pulsa _Crear pedido_ > Creando pedido
+ Creando pedido
    + Descripción: Vista con cliente y dirección.
    + Eventos:
        + El usuario cancela > Consulta
        + El usuario introduce los datos y acepta: Se crea el pedido > Consulta

Crearemos un caso de uso *crear_pedido_desde_grupo_devolucion*
+ Entrada:
    + Cliente
    + Dirección de entrega del cliente
    + Lista de grupos de devolución

+ Condiciones
    + El cliente, la dirección y el grupo existen
    + El grupo no está asociado ya a otro pedido

+ Acción:
    + Crea el pedido para el cliente y grupos indicados

+ Eventos:
    + Se genera un evento *ventas.pedido_devolucion.creado* que incluye:
        + Lista de Id Grupo devolucion
    
+ Suscripciones:
    + *ventas.pedido_devolucion.creado* > Nuevo caso de uso en *ventas/grupo_devolucion/asociar_a_pedido* que asocia el grupo al pedido generado.
