# #MSC #H4812 Publicación DeCA, localización de artículos por código de barras, pistola de lectura

Los objetivos de este proyecto son:

+ Poder generar y publicar el documento DeCA y su código QR asociado.
+ Poder localizar artículos en la tabla de artículos leyendo uno de sus códigos de barra
+ Obtener una nueva pistola de lectura de códigos de barra

## Propuesta realizada a petición de:
Francisco

## Estructura

### App web Sucesores / DeCA
Crearemos la opción DeCA que permitirá:
    + Crear de forma manual los documentos DeCA
    + Memorizar cliente / proveedor y su dirección para futuros usos
    + Imprimir informe con QR

El DeCA también se publciará en la web de sucesores para su consulta a través del QR

### Almacén / Localización de artículo por barcode
Ampliaremos la extensión de múltiples barcodes para incluir un campo de lectura en la cabecera del maestro de artículos que nos permita buscar el artículo correspondiente al código indicado.

### Lector de códigos de barra
Lector inalámbrico
