# #SAN #H4770 Envío de correo con múltiples documentos (facturas) desde ficha de cliente

Los objetivos de este proyecto son:

+ Poder enviar a los clientes correos de forma directa desde su ficha de cliente y que contengan más de una factura adjunta

## Propuesta realizada a petición de:
Carmen

## Estructura

### Principal / Clientes. Multiselección y envío de facturas
Añadiremos a la pantalla de clientes, subpestaña factura los siguientes controles:

+ Botón multiselección: Abre / Cierra el modo de multiselección.

Operativa: Para enviar a un cliente varias facturas:
+ Abrimos la multiselección con el nuevo botón
+ Seleccionamos las facturas a enviar
+ Pulsamos el botón de enviar correo
    + Se abre la ventana de envío de correo actual con todos los adjuntos seleccionados.

El funcionamiento normal de seleccionar una única factura y pulsar el botón enviar seguirá funcionando como hasta ahora.
