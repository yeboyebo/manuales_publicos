# #SAN #H4772 Limpieza de archivos de gran tamaño asociados a incidencias

Los objetivos de este proyecto son:

+ Disminuir el peso de la base de datos de gestión documental eliminando documentos asociados a incidencias cuyo peso es superior a un umbral. Estos documentos suelen ser vídeos explicativos que no tiene sentido seguir almacenando una vez la incidencia ha sido cerrada o rechazada

## Estructura

### Gestión documental / configuración
Añadiremos a la pantalla los siguientes controles:

+ Días borrado documentos incidencia. Días desde la fecha de creación de la incidencia que se toman como mínimo para borrar documentos asociados
+ Tamaño (Mb) mínimo para eliminar los documentos

### Gestión documental / proceso periódico de borrado
Crearemos un proceso periódico que buscará documentos asociados únicamente a incidencias y que cumplan con los criterios de _Días borrado documentos incidencia_ y _Tamaño (Mb) mínimo para eliminar los documentos_ para incidencias en estado Cerrada o Rechazada. Los documentos serán borrados de la base de datos de gestión documental.
