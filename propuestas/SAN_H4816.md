# #SAN #H4816 Cierre automático de tareas al cerrar un trato o una incidencia

Los objetivos de este proyecto son:

+ Evitar tener tareas pendientes cuya entidad superior (trato o incidencia) ya haya terminado su ciclo de vida.

## Propuesta realizada a petición de:
Paloma

## Estructura

### Webapp Tratos / Cierre de tareas

Modificaremos el caso de uso *crm.trato.ganar* y *crm.trato.perder* 

+ Eventos:
    + Se genera un evento *crm.trato.ganado* / *crm.trato.perdido* que incluye:
        + Id Trato
    
+ Suscripciones:
    + *crm.trato.ganado* > Nuevo caso de uso en *crm/tareas/cerrar_tareas_trato* que marca como cerradas todas las tareas pendientes del trato.
    + *crm.trato.perdido* > (mismo caso de uso)

Vista app:

Añadiremos a la ventana de tratos el siguiente aviso que aparecerá cuando el trato se vaya a marcar como ganado o perdido y tenga tareas pendientes asociadas:

```
Vas a marcar este trato como Ganado / Perdido, tienes X tareas pendientes
¿Estás seguro de que quieres continuar y completarlas?
(Sí / No)
```

### Webapp Incidencias / Cierre de tareas

Modificaremos el caso de uso *crm.incidencias.cambiar_incidencia*

+ Eventos:
    + Se genera un evento *crm.incidencia.cerrada* / *crm.incidencia.rechazada* que incluye:
        + Id Incidencia
    
+ Suscripciones:
    + *crm.incidencia.cerrada* > Nuevo caso de uso en *crm/incidencias/cerrar_tareas_incidencia* que marca como cerradas todas las tareas pendientes de la incidencia.
    + *crm.incidencia.rechazada* > (Mismo caso de uso)

Vista app:

Añadiremos a la ventana de incidencias el siguiente aviso que aparecerá la incidencia se vaya a marcar como Cerrada o Rechazada y tenga tareas pendientes asociadas:

```
Vas a marcar esta incidencia como Cerrada / Rechazada, tienes X tareas pendientes
¿Estás seguro de que quieres continuar y completarlas?
(Sí / No)
```

### ERP CRM Incidencias / Cierre de tareas
Cuando desde el ERP se modifique una incidencia pasando su estado a Rechazada o Cerrada, se emitirá un evento *crm.incidencia.cerrada* / *crm.incidencia.rechazada*.
