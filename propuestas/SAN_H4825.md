# #SAN #H4825 Seguimiento de actividad de usuarios

Los objetivos de este proyecto son:

+ Conocer el comportamiento de uso de los usuarios en la aplicación a fin de determinar puntos de embudo y patrones a corregir. El seguimiento será para toda la aplicación y para todos los usuarios, y podrá activarse y desactivarse mediante una actualización.

## Estructura

### Seguimiento frontend: Navegación y tiempos
Modificaremos el router de la parte cliente para conocer en qué pantallas (urls) está el usuario y cuánto tiempo pasa en cada una

### Seguimiento backend: Comandos
Modificaremos el router de comandos del servidor para registrar los comandos de creación, modificación y borrado que reflejan la actividad de cada usuario.

En ningún caso guardaremos datos sobre el contenido de los comandos concretos (p.e. qué cliente estamos creando, solo que creamos un cliente)
