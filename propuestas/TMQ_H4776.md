# #TMQ #H4776 Control de producción de máquinas

Los objetivos de este proyecto son:
+ Generar una pantalla que nos permita ver el estado de fabricación de cada máquina a nivel de cada componente como hasta ahora se hace con hojas excel online.
+ Permitir la generación / consulta de pedidos y albaranes a proveedores desde la pantalla de control de fabricación.

## Estructura

### Artículos / Pestaña de compras
Crearemos un nuevo campo Ruta en la tabla de artículos por proveedor para indicar la opción de ruta a la que pertenece cada fase.

+ Ruta (número entero, valor por defecto 1)

### Ventas / Máquinas
Añadiremos a la tabla de líneas de pedido los siguientes campos:

+ Mapa de producción (JSON)
+ Estado: Pendiente, (progreso), Hecho. Progreso = (ej. 10020) indicando conjuntos pendientes (0), en curso (1), terminados (2)

Estructura de la pantalla:

Vista selección de máquinas: Muestra una lista de máquinas dentro de pedidos de cliente. Filtro por defecto: _No terminadas_. Campos a mostrar:

+ Referencia
+ Descripción
+ Pedido (cliente, código y fecha)
+ Estado (% de progreso)

Cuando se selecciona una máquina:

+ Si la máquina no tiene plan todavía (mapa de producción vacío), este se genera.

+ Se muestra la página de plan de producción dividida en dos partes:
    + Izquierda:
        + Botón regenerar árbol. No permitirá regeneración si hay pedidos o albaranes asociados a rutas que desaparecen en el nuevo árbol.
        + Cabecera con referencia y descripción de la máquina y datos del pedido
        + Estado global de la máquina
        + Lista de conjuntos con:
            + Referencia
            + Descripción
            + Estado de progreso
    + Derecha:
        + Botones:
            + Colapsar todo. Cierra todos los listados abiertos
            + Solo pendientes. Cierra todos los listados terminados y abre todos los pendientes o en curso

        + Árbol de producción del conjunto seleccionado en la parte izquierda. Sigue la siguiente estructura:
            - Si el nodo es un artículo compuesto, se muestran los siguientes campos:
                + Referencia compuesto
                + Descripción
                + Estado de progreso composición. Posibles valores:
                    + Pendiente: Color rojo. Todos los componentes pendientes.
                    + Terminado: Color verde. Todos los componentes terminados.
                    + En curso: Color naranja. Cualquier otro caso.

                + Listado expandible de componentes. Para cada componente, su árbol de producción

            - Si el nodo es una artículo no compuesto, se muestra:
                + Referencia
                + Descripción
                + Estado de progreso fases. Posibles valores:
                    + Pendiente. Color rojo. Todas las fases pendientes.
                    + Terminada. Color verde. Todas las fases recibidas
                    + En curso. Color naranja. Cualquier otro caso

                + Ruta de fases (para productos con más de una posible ruta). Podemos hacer clic sobre ella para cambiar de ruta, si no hemos hecho pedidos de ninguna de las fases de la ruta actual.
                + Listado expandible de fases de fabricación. Para cada fase:
                    + Orden
                    + Referencia fase
                    + Descripción fase
                    + Código fase
                    + Proveedor
                    + Estado. Posibles valores:
                        + Pendiente (no se ha hecho el pedido). Color rojo
                        + Pedido (se ha hecho el pedido). Color naranja
                        + Recibido (se ha hecho el pedido). Color verde

                    + Enlace a pedido / albarán
                    + Botón Pedir / Recibir / Borrar recepción dependiendo del estado.

## Notas de desarrollo
Estructura de mapa de fabricación de una máquina (línea de pedido)
```js
interface ComponenteBase = {
    referencia: string
    idarticulocomp: string
    tipo: "rama | hoja"
}

interface ComponenteRama extends (ComponenteBase) {
    componentes: ComponenteBase
}

interface Fase {
    id: string,
    idarticuloprov: string
    referencia: string
    nombreFase: string
    orden: number,
    cantidad: number
    idlineapedido: string | null
    idlineaalbaran: string | null
}

interface ComponenteHoja extends (ComponenteBase) {
    idRuta: string
    totalRutas: number
    fases: []
}

// Ejemplo
{
    mapa: [
        {
            referencia: "x",
            tipo: "rama" | "hoja"

            // Caso rama
            componentes: [ 
                {
                    ...componente
                }
                ...
            ],

            // Caso hoja
            ruta_id: string
            fases: [
                { id: string, idarticuloprov: string, nombre_fase: string, orden: number, cantidad: number, idlineapedido, idlineaalbaran}
            ]
        },
    ],
    pedidos: [
        { ruta: R1/R11,R111/.../F1, idlinea: X },
        ...
    ]
    albaranes: [
        { ruta: R1/R11,R111.../F1, idlinea: X },
        ...
    ]
},

```
